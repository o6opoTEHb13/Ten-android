# Тень — приватный мессенджер

[![Release](https://img.shields.io/github/v/release/o6opoTEHb13/Ten-android)](https://github.com/o6opoTEHb13/Ten-android/releases)

**Тень** — децентрализованный мессенджер, который работает даже без интернета. Никаких серверов, никакой регистрации, только ваше устройство и люди рядом.

---

## ✨ Возможности

- 🔵 **Bluetooth Mesh** — общайтесь без интернета, сообщения передаются между устройствами
- 🌐 **P2P через интернет** (libp2p) — прямое зашифрованное соединение
- 📡 **Nostr** — резервный канал связи через децентрализованные релеи
- 🔒 **Сквозное шифрование** — Noise Protocol (Curve25519 + ChaCha20-Poly1305)
- 📍 **Геолокационные чаты** — общайтесь с людьми рядом
- 📷 **QR-код из галереи** — отсканируйте скриншот, контакт добавится автоматически
- 🔗 **Пригласительные ссылки** — отправьте другу ссылку, и он добавит вас в контакты
- 🚫 **Нет серверов** — полная приватность, без регистрации и телефона
